Рабочая модель

Создавай квизы и делись ими с друзьями по ссылке

Это версия, которая подходит для GitHub Pages: без сервера, но уже умеет создавать квизы, сохранять их в браузере, делиться по ссылке и проходить тест.

Как это работает

  1. Создаешь квиз с вопросами и вариантами ответов.
  2. Сайт генерирует ссылку для друзей.
  3. Друг открывает ссылку и проходит тест.
  4. Результат показывается сразу после завершения.

Важно

Эта модель работает без базы данных. Поэтому квизы хранятся в браузере автора, а ссылка содержит сам квиз. Для общей статистики всех друзей на одном аккаунте позже подключим backend.
